# CircuitPython environment

Tested environment:

- CircuitPython 10.3.0
- Board ID: `lolin_s2_mini`

Libraries used by the firmware:

- `adafruit_requests`
- `adafruit_connection_manager`
- `neopixel`

Built-in CircuitPython modules used by the program include `gc`, `os`,
`random`, `ssl`, `time`, `microcontroller`, `socketpool`, and `wifi`.

Install compatible versions from the CircuitPython Library Bundle matching the
major CircuitPython version used on the board.
